Pyxis Desktop 0.3.1 for **Windows x64** and **Debian / Raspberry Pi OS ARM64**.

- Brings the current Pyxis website’s Skyline VPR, TARS mission tools, local archive search, route-risk and measurement updates to the desktop.
- Keeps the offline map manager, Point Inspector, crew locations, site attachments, and existing desktop APIs.
- Retires dated draft notes and removes old documentation timestamps from the desktop snapshot.

Skyline results rank candidate matches and route risk is a planning aid. Install optional ARES neural weights separately. The optional platform voice ZIP adds offline spoken replies.

Run the Windows setup executable, or install the Debian package with `sudo apt install ./Mars-Field-Atlas-0.3.1-arm64.deb`. The release includes checksums and verification for both builds.
