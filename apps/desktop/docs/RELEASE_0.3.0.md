Pyxis Desktop 0.3.0 for **Windows x64** and **Debian / Raspberry Pi OS ARM64**.

- Pyxis interface with offline map selection, source downloads, and site attachments.
- Point Inspector for arbitrary locations in 2D and 3D, with sourced data and mission actions.
- Local APIs for crew locations, dead reckoning, external fixes, terrain, route evaluation, observations, environment, seismic records, and suit telemetry.
- Offline English speech recognition and local GGUF inference. Install compatible ARES model weights separately. The platform-specific voice ZIP adds optional offline spoken replies.

Run the Windows setup executable, or install the Linux package using `sudo apt install ./Mars-Field-Atlas-0.3.0-arm64.deb`. Check the downloads against SHA256SUMS.txt. See BUILD_VERIFICATION.json for the verified source revision and asset inventory.
