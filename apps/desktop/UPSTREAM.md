# Desktop source provenance

The desktop app is maintained under `apps/desktop`, with a separately built renderer snapshot in `web/`.

This release integrates the Pyxis website in `apps/web` at repository commit `c9e11a9ca19045624ea1f50800c90dce05318d6d` over the earlier renderer baseline `2e34ef7ef4a5b35430eb92ca720e6a24c93fb51a`. Desktop offline adapters, file attachments, persistence and local APIs are maintained in the desktop module.

Original partner routing authorship and scientific data credits remain with their files. See [third-party notices](THIRD_PARTY_NOTICES.md) and the original [routing provenance](web/routing/upstream-source.json).
