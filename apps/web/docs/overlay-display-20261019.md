# Scientific overlay display refinement — 19 October 2026

Hydrated-mineral detections now use a shared display renderer in 3D, 2D and Compare. Individual records are lilac dots; nearby records become compact numbered badges with an 11 px font. Screen anchors remain at an actual source coordinate and stay more than 42 px apart. Badges split as the view enlarges. The globe excludes the far hemisphere and leaves an inset at the limb so counts do not float outside the planet. Local placement reads only already-loaded terrain, including display relief exaggeration; it does not request another terrain grid. Hover text preserves product identifiers. The 1,847 source records and coordinates are unchanged.

Static raster layers and time-dependent environment fields use fixed color families for terrain, minerals, water/ice, thermal and atmospheric quantities. Signed quantities use a diverging scale, aspect uses a cyclic compass scale, and categorical terrain layers use distinct swatches with names instead of a misleading continuous ramp. Legends include a midpoint for continuous scales. Existing elevation, magnetic and NASA-style wind scales retain their data-specific colors.

All scientific legend cards share typography, spacing, contrast and responsive placement. Environmental cards give a short model/time label; full source metadata remains available under the selected layer in Layers. Compare cards dock near the bottom of the 3D half. Overlays still use the chosen tint and allow the full 0–100% range.

No numerical source products, units, time behavior, missing-data masks, native cell values or coverage extents were changed. Mineral grouping is a screen display operation, not a deposit boundary or mineral abundance estimate. Published source gaps stay unknown. Model data remains labeled as modeled data.

Validation: 203 JavaScript tests, production build, and browser checks of mineral grouping at multiple scales in 3D/2D/Compare, water-equivalent hydrogen display, categorical terrain source keys, and repeated layer switching. Saved-session restoration also ignores hidden component controls for non-raster layers, preventing an unintended raster request on refresh. The new tests preserve all visible detection records, prevent overlapping badges, reject invalid/offscreen projected positions, check hit testing, and verify fixed/cyclic/categorical scales and transparent unknown values.
