# Gray imagery patches follow-up — 2026-11-03

The previous continuity change did not cover every incomplete-image path. Correct two narrowly scoped cases while retaining fixed movement detail, bounded LRU cache and late-result protection.

1. Custom image preparation (`contextCanvas`, optical gap composition, quality-mask recording and fallback cropping) can finish after Cesium's original network-completion render has passed. With `requestRenderMode`, finishing pixels must explicitly request another render. The old `contextReady` only batched place/model readouts. `imageryReadyCallback` now immediately requests rendering on every completion; only UI readout work is coalesced into an animation frame. Applies to all existing global imagery providers using the callback, including recovered fallback images.
2. `AbortError` is not sufficient evidence that a map consumer was cancelled. An interrupted download on a live consumer still needs the existing measured-ancestor fallback. Only `request.cancelled` now bypasses fallback. Real camera cancellations still reject; genuine failures still use bounded recovery and maintain source-level metadata.

Direct source inspection of reported failing CTX tile `10/378/448`: public ArcGIS source returned HTTP 200, JPEG content type, 31,697 bytes, JPEG start signature but no terminating JPEG marker. The existing proxy correctly rejects this incomplete photograph. This change does not relax byte validation or invent missing imagery. External source damage may continue to limit available resolution.
