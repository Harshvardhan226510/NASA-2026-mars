# Website update — 8 November 2026

This update synchronizes the tested local Atlas website with the private repository. It preserves the repository's existing data, algorithms and preparation tools.

## Features included

- **Personal sites:** add a named marker with a description using coordinates, the map crosshair or a click on the 3D/2D map. Edit and remove saved markers through **Explore → My sites**. Optionally designate Science, Minerals or Resources sites of value for route planning. Personal sites have a separate visibility layer, persist in browser storage, and travel with saved/shared missions. User annotations do not become published resource evidence.
- **Separate site evaluation:** **Missions → Landing & base sites** offers independent landing and base subsections. **Plan Mission → Evaluate a base station site** opens the base subsection directly. Landing assesses the footprint and surrounding terrain, with a vehicle elevation ceiling. The base preset prioritizes sunlight, ice evidence and nearby resources alongside buildable terrain. Each form retains its settings and supports four candidates.
- **Evaluated site markers:** choose a location by map click, crosshair or coordinates, evaluate it, then mark/save it in My sites. The editable summary records evaluation type, score bounds, evidence coverage, terrain status, footprint and source sampling. Re-saving updates the same marker. Recalculation keeps candidate centres and prompts an explicit saved-marker update. See [User-marked sites](user-marked-sites.md) for the workflow and limitations.
- **Landing/base pair comparison:** compare evaluated candidates within a straight-line distance budget, with terrain eligibility and bounds based on the weaker component. Export the comparison as JSON or a readable report. Scores remain editable project preferences, with missing evidence and unresolved hazards shown explicitly.
- **Color appearance:** an optional persistent color-enhancement control adjusts the photographic color stack's brightness, contrast and saturation, independently of scientific overlays. It can be disabled in Layers.
- **Coordinate search:** Find a place accepts latitude/longitude pairs separated by spaces or commas, with or without decimals, and moves the view to the entered location.
- **Thermal-inertia coverage:** mask constant polar fill rows in the delivered reference grid, retain measurements in mixed rows, label the 2-pixel/degree sampling, and version the display cache for the corrected mask.

## Validation and scope

All 436 JavaScript tests pass in the synchronized checkout, and the production build succeeds. Browser checks of the equivalent local website cover independent evaluation forms, both map-picking modes, real terrain evaluations, saving both candidate types, value designation, reload persistence and the direct Plan Mission shortcut. No imagery datasets are duplicated. Local dependencies, credentials, caches, generated builds and standalone cinematic preview assets are excluded from this website update.

The original collaborator repository is not changed, and this update does not open a pull request or request a manual Vercel deployment.
